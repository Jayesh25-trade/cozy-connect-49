# Developer Guidelines - Cozy Connect (LoveNest)

## Overview

Cozy Connect (LoveNest) is a private, free, unlimited web-based video, voice, and interactive chat application designed for couples. It features direct peer-to-peer WebRTC connections, live text chat, collaborative notes, floating emoji reactions, and cozy ambient themes & sounds.

## Technology Stack

- **Framework**: TanStack Start + TanStack Router
- **UI & Styling**: React, Tailwind CSS v4, Lucide Icons, Radix UI primitives
- **Real-Time Communication**: WebRTC via PeerJS
- **Bundler & Build Tool**: Vite

## Key Principles

1. Maintain clean, reliable WebRTC state handling.
2. Keep user privacy paramount — direct device-to-device streaming without intermediate recording servers.
3. Keep the visual design romantic, candlelit, and intuitive.
